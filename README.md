# AD Software Manager

Интерактивная консольная утилита на PowerShell (меню в стиле `sconfig`) для **инвентаризации и удаления установленных программ и приложений** на всех компьютерах домена Active Directory — пользовательских ПК, серверах и виртуальных машинах.

> [English version](README.en.md)

## Что показывается

- Программы из реестра `Uninstall`: `HKLM` (x64 и x86) и `HKU\<SID>` **всех профилей** пользователей (незагруженные `NTUSER.DAT` временно подключаются).
- Приложения **Microsoft Store (Appx)** для всех пользователей.
- Название, версия, издатель, размер, дата установки, источник.
- Системные компоненты, обновления и служебные пакеты по умолчанию скрыты (клавиша `S`).

## Возможности

- Раздельные таблицы: **компьютеры пользователей** и **серверы / ВМ** (по `OperatingSystem` в AD).
- Выбор, что сканировать: все / только пользовательские / только серверы, а также **отдельные OU** (с вложенными). Результаты накапливаются.
- **Индикатор выполнения** и прерывание по `Esc`.
- Сводка «программа → на скольких компьютерах» с количеством версий.
- **Удаление по имени** (с фильтром по версии, в том числе маской `11.*`) со всех или выбранных компьютеров; выбор отдельных строк в `Out-GridView`.
- Подтверждение `YES`, лог (с командой удаления), экспорт в CSV, список недоступных компьютеров.

## Как выполняется удаление

| Тип записи | Команда |
|------------|---------|
| MSI | `msiexec /x {GUID} /qn /norestart` |
| Есть `QuietUninstallString` | выполняется она |
| Inno Setup (`unins000.exe`) | добавляются `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART` |
| Приложение Store | `Remove-AppxPackage -AllUsers`; если пакет остался (например, ошибка `0x80073D19`) — удаление отдельно по каждому пользователю; по запросу — ещё и из образа системы. Результат проверяется по факту отсутствия пакета |
| Остальные | только если вы укажете доп. аргументы (например, `/S`); иначе пропускаются |

Каждое удаление ограничено по времени (`-UninstallTimeoutSec`, по умолчанию 900 с); зависший процесс останавливается. Код `3010` означает «нужна перезагрузка» — компьютер скрипт не перезагружает.

## Требования

- Windows PowerShell 5.1 (PowerShell 7 не проверялось).
- Модуль **ActiveDirectory** (RSAT).
- Права администратора на целевых компьютерах.
- На целевых компьютерах включён **WinRM (TCP 5985)**. Резерва через DCOM нет.
- Для выбора строк вручную нужен `Out-GridView`.

## Быстрый старт

```powershell
git clone https://github.com/YOUR-USERNAME/ad-software-manager.git
cd ad-software-manager

powershell -ExecutionPolicy Bypass -File .\Manage-DomainSoftware.ps1
# или
.\Manage-DomainSoftware.ps1 -Domain corp.example.com -StaleDays 60 -UninstallTimeoutSec 600
```

Программа **сначала показывает меню**; сканирование запускается пунктом `1`.

## Параметры

| Параметр               | По умолчанию               | Описание                                                     |
|------------------------|----------------------------|--------------------------------------------------------------|
| `-Domain`              | `$env:USERDNSDOMAIN`       | DNS-имя домена AD                                            |
| `-StaleDays`           | `90`                       | Пропускать компьютеры, не заходившие в домен более N дней    |
| `-UninstallTimeoutSec` | `900`                      | Максимум секунд на удаление одной программы                  |

## Меню

```
  Сканирование
   1) Запустить сканирование с текущими параметрами
   2) Тип компьютеров: [все компьютеры]  (нажмите, чтобы переключить)
   3) Область (OU): [весь домен corp.example.com]
   C) Очистить результаты

  Просмотр
   4) Программы: компьютеры пользователей
   5) Программы: серверы и виртуальные машины
   6) Сводка (программа → на скольких ПК)
   U) Недоступные компьютеры

  Удаление
   7) Удалить программу по имени (все / выборочно)
   8) Выбрать строки (Out-GridView) и удалить

  Прочее
   S) Системные компоненты и обновления: скрыты
   A) Приложения Microsoft Store: показаны
   E) Экспорт в CSV
   0) Выход
```

Клавиши работают и в русской раскладке.

## Безопасность и ограничения

- **Удаление необратимо.** Проверьте на пилотной OU и на одном компьютере для программ, которым нужны свои аргументы тихого режима.
- Программы, установленные только для одного пользователя, могут не удаляться в контексте администратора.
- Нажатие `Esc` во время удаления прекращает ожидание, но уже запущенные на компьютерах процессы удаления продолжат работу.
- Лог (`DomainSoftwareManager.log`) и CSV содержат имена ПК и пользователей — не публикуйте их (они в `.gitignore`).
- Ответственность за использование лежит на вас (см. лицензию).
